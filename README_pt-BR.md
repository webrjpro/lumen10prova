# Lumen10 Prova

Este repositório reúne a atividade **Lumen10 Prova 1.3.0** e sua regra de acesso obrigatória **1.2.0**, para Moodle **5.1 e 5.2**.

Baixe os dois ZIPs em [Releases](https://github.com/webrjpro/lumen10prova/releases). A regra deve ser instalada em `mod/quiz/accessrule/lumen10prova`; a atividade, em `mod/lumen10prova`. Acrescente `public/` conforme a estrutura do Moodle. O ZIP geral de código-fonte do GitHub não é um plugin único para instalação.

Consulte a [documentação da atividade em português](mod_lumen10prova/README_pt-BR.md), o [README consolidado em inglês](mod_lumen10prova/README.md) e o [rastreador público](https://github.com/webrjpro/lumen10prova/issues).

Os dois componentes têm cadastro próprio no Marketplace. A publicação do código no GitHub não representa aprovação oficial. Faça backup antes de atualizar; o Moodle continua responsável por questões, respostas e notas nativas.
